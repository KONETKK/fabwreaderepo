# Метки разделов FaberlicCat

Эта папка содержит только JSON с переходами к разделам каталога для приложения FaberlicCat.
ZIP-архивы в корне репозитория и их адреса не изменяются.

Путь карты: `<catalogId>/<Git-blob-SHA-исходного-ZIP>.json`.
Публичный адрес: `https://raw.githubusercontent.com/KONETKK/fabwreaderepo/main/catalog-navigation/faberliccat/<catalogId>/<SHA>.json`.

`archiveSha1` вычисляется как SHA-1 от `blob <размер ZIP в байтах>\0` и исходных байтов ZIP.
Это Git blob SHA, а не обычный SHA-1 файла. `image` — точное имя изображения в архиве
без пути к папке. Все пять ID для cosmetics обязательны: `new`, `fragrance`, `care`, `home`, `gifts`.

Для следующего выпуска:

1. Проверьте изображения начала разделов в новом исходном ZIP.
2. Создайте новую карту schemaVersion 2 с его SHA. Генератор находится в проекте приложения:
   `tools/prepare_catalog_navigation.py`; он открывает ZIP только для чтения.
3. Добавьте JSON в `cosmetics/` и опубликуйте его до появления нового ZIP у пользователей.
4. Проверьте доступность raw-адреса без авторизации. Сохраните копию в assets проекта приложения.

Не удаляйте карты старых выпусков. Опубликованные карты считаются неизменными: приложение
сохраняет их локально. Не добавляйте метки внутрь ZIP и не изменяйте существующие файлы
репозитория ради публикации JSON. Для health и avon текущие кнопки открывают обложки.
