Политика конфиденциальности

Приложение «Фаберлик - каталог и распаковки!» (далее — «Приложение»). Разработчик: Безродний Ярослав Андреевич, независимый консультант Faberlic (ID 745374838). Дата вступления в силу: 18.08.2026.

1. Общие положения

Приложение является персональной площадкой независимого консультанта и НЕ является официальным приложением АО «ФАБЕРЛИК». Приложение не собирает, не хранит и не передаёт персональные данные пользователей. В Приложении отсутствует регистрация и учётные записи.

2. Обрабатываемые данные

Приложение не собирает персональные данные. Контент (каталоги, изображения, видео) загружается из публичных источников и хранится только локально на устройстве (кэш). Разработчик не имеет доступа к данным на устройстве пользователя. Аналитика, трекеры и рекламные SDK в Приложении не используются.

3. Используемые разрешения

  • INTERNET, ACCESS_NETWORK_STATE — загрузка каталогов и видео;
  • POST_NOTIFICATIONS — уведомления об акциях, только с явного согласия пользователя;
  • RECEIVE_BOOT_COMPLETED — восстановление расписания уведомлений после перезагрузки устройства.

4. Сторонние сервисы

Регистрация консультантом выполняется на официальном сайте faberlic.com — данные обрабатывает АО «ФАБЕРЛИК» согласно его политике конфиденциальности. Видеоролики открываются в VK (vk.com) — действует политика конфиденциальности VK. Графика: freepik.com.

5. Права субъекта персональных данных

Поскольку Приложение не собирает персональные данные, для реализации прав (доступ, исправление, удаление) достаточно удалить Приложение — весь локальный кэш будет удалён автоматически. По любым вопросам конфиденциальности обращайтесь по контактам в разделе 8.

6. Дети

Приложение предназначено для аудитории 12+ и не направлено на сбор данных детей.

7. Изменения политики

Разработчик может обновлять настоящую политику. Новая редакция публикуется по этому же адресу и вступает в силу с момента публикации.
